Driftline

See how your prompts change before an AI model is retired.

The problem

AI providers retire models on a schedule. Anything with a model name written into its code stops working on that date. Swapping the name is easy. Knowing whether the replacement still returns valid JSON, keeps the same tone and refuses the same things is not.

How it works

  1. Scan. Finds model IDs from OpenAI, Anthropic and Google in your code and config files.
  2. Check. Compares them against announced retirement dates and recommended replacements.
  3. Test. Runs the prompts you list in .driftline/prompts.yml on both the current and the replacement model.
  4. Report. Opens a GitHub issue with a side-by-side comparison, 90 days before retirement.

It runs in your own CI with your own API keys. Your keys and prompts never leave your pipeline.
